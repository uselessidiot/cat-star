# 고양이의 별 — 현재 개발 상태 / 집에서 이어 하기

최종 갱신: 2026-09-18

## 1. 지금 구현된 핵심 경험

### 밤하늘과 기억별

- 메인 화면은 고양이의 밤하늘과 기억별을 탐색하는 장면이다.
- 기억별은 빈 별과 사진이 담긴 별을 구분하며, 활동 태그·깊이·색감·별 모양을 반영한다.
- 별을 클릭하면 기억 상세를 열고, 사진 여러 장을 볼 수 있다.
- 단일 기억별 생성, 빈 별 채우기, 수정·삭제, 사진 추가/삭제 흐름이 있다.
- `/memories`에는 다시 보는 기억(앨범) 화면이 있다.

### 데이터 / 인증

- 프론트는 `lib/memory-api.ts`를 통해 `/api/cat-profile`, `/api/memory-stars` API를 우선 사용한다.
- API 실패 시 기존 IndexedDB 경로가 롤백 대비로 남아 있다.
- 사진 제약: 이미지 파일만, 1장 최대 8MB, 별 하나당 최대 6장.
- 익명으로 바로 시작할 수 있고, `내 별 저장`에서 이메일/비밀번호 계정으로 승격하거나 로그인할 수 있다.
- 자세한 계약은 [AUTH_API.md](./AUTH_API.md), 데이터/백엔드 계약은 [BACKEND_HANDOFF.md](../BACKEND_HANDOFF.md)를 참고한다.

## 2. 중심별(루루) 인터랙션 현황

중심별을 열면 일반 메인 고양이는 숨기고, 중심별 장면 안의 고양이 객체만 사용한다.

| 사용자 행동 | 현재 동작 |
| --- | --- |
| 밤하늘/지면 클릭 또는 터치 | 클릭한 가로 위치의 지면까지 걷기 스프라이트로 이동. 하늘 높이로 떠오르지 않음. |
| 루루 클릭 | 그루밍 4프레임이 천천히 재생되고, 머리 위에 흐린 하트가 떠올랐다 사라짐. |
| 빈 밥그릇 클릭 | 사료가 채워짐 → 루루가 밥그릇으로 걸어감 → 먹기 4프레임 → 잠시 후 그루밍. |
| 밥 먹는 중 | 중복 클릭을 막고, 먹기 스프라이트 안의 밥그릇만 보이게 처리. |

### 현재 애셋

- `public/assets/cat-back-v3.png` — 기본 대기 고양이
- `public/assets/cat-walk-sprite-v2.png` — 걷기 4프레임
- `public/assets/cat-groom-sprite-v1.png` — 그루밍 4프레임

## 4. 로컬 실행

PowerShell에서 프로젝트 폴더로 이동한다.

```powershell
cd "C:\Users\user\Documents\Codex\2026-09-07\new-chat\cat-star"
pnpm install
pnpm dev
```

그 다음 브라우저에서 `http://localhost:3000`을 연다.

### 확인 순서

1. 중심별(루루의 별)을 연다.
2. 밥그릇을 클릭한다.
3. 루루가 걸어가서 먹고, 식사 뒤 그루밍하는지 확인한다.
4. 루루를 클릭해 하트와 느린 그루밍이 나오는지 확인한다.
5. `+ 기억별 만들기`에서 사진을 올린 뒤 새로고침해도 기억이 남는지 확인한다.

## 5. Git 상태와 집에서 가져오기

현재 기능 커밋:

```text
18a6c0f Add interactive feeding and grooming
```

이 문서 커밋도 함께 만든 뒤, 현재 컴퓨터에서 아래를 실행해 GitHub에 올린다.

```powershell
git push origin main
```

집 컴퓨터에서는 다음 순서로 최신 내용을 받는다.

```powershell
cd <집 컴퓨터의 cat-star 폴더>
git pull --ff-only origin main
pnpm install
pnpm dev
```

`git pull` 전에 수정 중인 파일이 있다면 먼저 `git status`로 확인하고, 필요하면 별도 커밋하거나 `git stash` 후 진행한다.

### 포함하지 않은 파일

- `public/assets/star-hideout-v1.png`은 숨숨집 실험용 미추적 파일이며 현재 화면에서 사용하지 않는다.
- Git에 올릴 필요가 없으므로 `git add .` 대신 필요한 파일만 선택해 add 하는 것을 권장한다.
- 필요 없으면 나중에 직접 삭제해도 된다.

## 6. 다음 우선순위 제안

1. **실기기 모바일 점검** — 터치 스크롤, 별 클릭, 밥그릇·고양이 hit area, 화면 하단 safe area 확인.
2. **고양이 행동의 상태 전환 보정** — 먹기→그루밍 사이 여백, 밥그릇 위치·크기, 하트 양을 실제 사용감으로 조절.
3. **사용자 데이터 E2E** — 계정 생성/로그인 후 다른 브라우저에서도 사진·기억별이 유지되는지 확인.
4. **성능 정리** — 큰 PNG를 WebP/AVIF로 전환할지, 별이 많이 생겼을 때 렌더링 비용을 점검.
5. **추가 행동은 나중에** — 하품, 기지개, 별을 바라보기는 지금의 밥·그루밍 감각이 안정된 후 추가한다.

## 7. 작업 원칙

- 화면을 관리 도구나 게임 HUD처럼 만들지 않는다.
- 모든 움직임은 빠른 효과보다 느리고 따뜻한 장면 전환을 우선한다.
- 새 UI를 추가할 때는 고양이·밤하늘·기억별보다 먼저 눈에 띄지 않게 한다.
- 중심별의 고양이는 정적 이미지 이동이 아니라 행동별 스프라이트를 사용한다.
